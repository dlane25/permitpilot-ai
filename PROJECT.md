# PermitPilot AI

PermitPilot AI is an autonomous permit and compliance operations platform for contractors.

## Mission

Turn construction project information and documents into a submission-ready permit package while minimizing repetitive administrative work.

## Core Workflow

1. Understand the project goal.
2. Extract project information.
3. Determine jurisdiction.
4. Identify permit requirements.
5. Analyze submitted project documents.
6. Detect missing or conflicting compliance requirements.
7. Quantify risk and likely delay impact.
8. Prepare permit application artifacts.
9. Escalate consequential decisions for human approval.
10. Resume autonomous execution after approval.
11. Produce a complete audit trail and measurable impact summary.

## Primary Demo

Oak Ridge Residence

A new single-family residential construction project demonstrating the full PermitPilot workflow from intake through permit-package readiness.

## Agent Governance

PermitPilot follows:

observe -> plan -> execute -> validate -> quantify -> escalate when required -> continue -> record

Safe, reversible actions may continue autonomously.

Material, uncertain, or consequential actions require human approval.
