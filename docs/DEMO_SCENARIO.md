# Oak Ridge Residence Demo

## Project

Oak Ridge Residence

## Type

New single-family residential construction

## Demo Goal

Prepare this project for permit submission.

## Demo Story

1. User opens the Oak Ridge Residence project.
2. User starts autonomous permit review.
3. PermitPilot extracts project information.
4. PermitPilot determines jurisdiction.
5. PermitPilot identifies required permits.
6. PermitPilot analyzes uploaded project documents.
7. PermitPilot detects missing compliance information.
8. PermitPilot quantifies likely review-delay exposure.
9. PermitPilot prepares application materials.
10. PermitPilot encounters one material decision.
11. Human reviews evidence and approves the recommendation.
12. PermitPilot resumes.
13. PermitPilot validates the package.
14. Project reaches Permit Package Ready.
15. Dashboard shows autonomous actions, human decisions, issues prevented, time saved, and estimated delay avoided.

## Demo Target Metrics

Autonomous actions: 40+
Human decisions: 1-2
Documents analyzed: 10+
Issues prevented: 2+
Estimated administrative time saved: 6+ hours
Estimated delay avoided: 3-7 days
