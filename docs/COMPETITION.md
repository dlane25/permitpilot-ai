# Competition Requirements

PermitPilot AI is being built for Agents for Humans.

## Track

Professional Agents

## Competition Goal

Build an agent that performs meaningful repetitive professional work end-to-end while escalating decisions that require human judgment.

## Required Technical Direction

- Strands Agents SDK
- Public GitHub repository
- MIT license
- Working agentic loop
- End-to-end autonomous workflow
- Human approval for consequential decisions
- Architecture diagram
- README and setup instructions
- Demo video no longer than five minutes

## Judging Priorities

1. Technical Implementation
2. Design
3. Potential Impact
4. Creativity and Originality
5. Presentation

## PermitPilot Differentiators

- Goal-driven workflow rather than prompt-driven chat
- Real autonomous execution
- Human decision queue
- Evidence-backed recommendations
- Structured audit history
- Measurable time and delay savings
- AWS-native agent deployment
